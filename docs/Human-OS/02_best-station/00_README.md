## 今回の主要変更

- 案内役を、人間観察が鋭く最後は味方になるギャルへ変更
- 本診断のトップ・質問・結果・Aboutを、同一のギャルPOPビジュアルへ統一
- 質問見出し・結果の大見出しは、大げさな日本語ディスプレイ文字で強く見せる
- 本文・補足・回答ボタンはNoto Sans JP系を基礎に、可読性を維持する
- 暖色ベース、ビビッドな差し色、太い枠、ステッカー風ラベル、オフセット影を採用
- 一画面の装飾量を制限し、分析の信頼感とスマートフォンの読みやすさを守る
- 定量ロジックを根拠にしつつ、結果の見せ方は定性分析を主役にする
- 主結果1駅、別候補2駅に加えて「惹かれやすいけど、無理が出やすい駅」0〜1駅を追加

## 適用範囲

ギャルPOPのデザイン変更は`best-station`診断内だけに適用します。Human OS共通トップ、ビジマル診断、他診断のフォント・色・コンポーネントは変更しません。
