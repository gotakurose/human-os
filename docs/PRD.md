# PRD — Product Requirements Document

> **注意：** 「Human OS」は現時点でのプロジェクト仮称です。正式サービス名は後日決定します。

---

## プロダクトの目的

本プロジェクトは「自分を知る」をテーマにした**固定タイプ診断プラットフォーム**です。

このプロジェクトの本質は「AI診断サイト」ではありません。

- **固定タイプ診断を量産できる仕組みを作る**
- **各診断の結果を将来的に Human Profile へ統合する**
- **100種類以上の診断をデータ追加だけで増やせるプラットフォームを構築する**

診断を「作る」のではなく、診断が「増やせる仕組み」を作ることが最大の目的です。

### なぜ固定タイプ制か

- MBTI のように「自分は○○タイプだった」と他者に伝えられる共有体験を重視する
- AI による毎回異なる個別生成では「友達と比べる」「同じタイプで盛り上がる」体験が生まれない
- 結果の再現性・一貫性があることで、SNS 拡散・口コミが起きやすい
- 無料で完結した体験を提供しつつ、有料 AI レポートへの自然な導線を設計できる

### AI の役割について

このプロジェクトにおける AI の役割は**限定的かつ明確**に定義します。

| AI を使う範囲 | AI を使わない範囲 |
|---|---|
| 診断の質問・タイプ設計の補助 | 無料診断の結果生成 |
| タイプ別コメント候補の下書き | スコアリング・タイプ判定 |
| 有料詳細レポートの個別生成 | レーダーチャートの描画 |
| Human Profile の統合分析（将来） | キャラクター・コメントの表示 |

無料診断の結果は**固定タイプ・固定結果文・固定キャラクター・固定コメント**で構成します。AI リクエストコストはゼロ。大量アクセスにも耐えられます。

## ターゲットユーザー

### プライマリ

- 20〜35歳の社会人（自己理解・キャリア志向が強い層）
- 自己分析に興味があるが、本格的なコーチングは高くて手が出ない人
- SNS で自分の結果をシェアしたい人

### セカンダリ

- 就活生・転職検討中の人（自己 PR 材料として使う）
- チームビルディングに使いたいマネージャー・人事担当者（将来の BtoB 展開）

### 行動特性

- スマートフォン主体で閲覧
- 結果をスクリーンショットして X / Instagram に投稿する
- 「友達にも教えたい」「友達の結果も見たい」という比較欲求が強い

## コア体験

```
診断を受ける（3〜5分）
→ 固定タイプ・キャラクター・能力値チャートが表示される
→ 「あなたは○○タイプです」という共有可能な結果を得る
→ X / Instagram でシェア or 友達に共有
→ 他の診断も受けてみる
→ 将来：Human Profile に複数診断の結果が統合される
→ 有料詳細レポートへの導線
```

### 体験設計の原則

1. **結果は固定** — 同じ回答なら必ず同じタイプになる（再現性・一貫性）
2. **結果は共有できる** — タイプ名・キャラクター・能力値がビジュアルで伝わる
3. **診断は短く** — 20問以内を基本とする。離脱防止
4. **次の診断への導線** — 結果ページに「他の診断も試す」を常設
5. **有料への自然な導線** — 無料結果で満足感を与えつつ「もっと深く知りたい」欲求を刺激する

## 最初に作るMVP（Phase 1）

**診断名：社会人能力値診断**

### 概要

20問の質問で5つの能力軸をスコアリングし、16タイプのいずれかに分類する。

### 5つの能力軸

| 軸 | 測定する特性 |
|---|---|
| 論理力 | 論理的思考・課題の構造化・根拠に基づく判断 |
| 実行力 | 行動の速さ・やりきる力・タスク管理 |
| 営業力 | 伝える力・人を動かす力・対外的な交渉力 |
| 創造力 | アイデア発想・新しい視点・課題の再定義 |
| 管理力 | チーム・プロセス・品質・リスクの管理 |

### 16タイプ設計

MBTI と同じく「同じタイプだった」という共有・比較体験を生むため、最初から **16タイプ固定**で設計する。

- 5軸のスコア分布から最も特徴的な軸の組み合わせでタイプを決定
- 各タイプにはタイプ名・キャラクター・固定コメント・強み・弱みを事前定義
- AI による個別生成は行わない

### 無料版の結果構成

- レーダーチャート（5軸）
- タイプ名（16タイプのいずれか）
- タイプ専用キャラクター画像
- 固定タイプ説明文
- 固定「強み」「弱み」コメント
- 相性タイプの紹介
- 「他の診断も試す」導線
- アフィリエイトリンク（タイプ別推薦コンテンツ）

### 共有

- OGP 画像にタイプ名・チャート・キャラクターをビジュアル表示
- X / Instagram への1クリックシェア

### MVP の収益化（初期〜将来拡張）

MVP 時点では Google AdSense を中心に収益化し、段階的に以下を追加できる設計にする。

| 収益源 | 導入タイミング |
|---|---|
| Google AdSense | Phase 1（MVP） |
| ビジネス書籍アフィリエイト | Phase 1（MVP） |
| 転職サービスアフィリエイト | Phase 2 以降 |
| AI ツールアフィリエイト | Phase 2 以降 |
| タスク管理ツールアフィリエイト | Phase 2 以降 |
| 有料詳細AIレポート | Phase 4 以降 |

### MVP の成功基準

- 社会人能力値診断が Vercel で公開されている
- 結果ページが X / SNS シェア可能な OGP を持つ
- 診断エンジンが JSON データ追加だけで第2・第3の診断を追加できる状態になっている

### KPI（ローンチ後1ヶ月）

- ページビュー：1,000 PV/月
- 診断完了率：60% 以上
- SNS シェア数：50 以上

## 将来構想

### 診断コンテンツ拡張

プラットフォームの骨格ができれば、以下のような診断を JSON データ追加だけで増やせる。

- 家買いたい？現在地チェッカー（ライフプランニング系）
- オリジナル16タイプ性格診断（性格系フラッグシップ）
- お金の使い方タイプ診断（マネー系）
- 恋愛依存度チェッカー（人間関係系）
- 副業向き職種診断（キャリア系）
- 睡眠タイプ診断（ライフスタイル系）
- …100種類以上を継続追加

### Human Profile（最重要将来機能）

複数の診断結果を1つのプロフィールページに集約する。

- `https://{サービスドメイン}/profile/{username}` で共有可能
- 「社会人能力値：リーダータイプ」「性格：○○型」など複数の診断結果が並ぶ
- 有料AIレポートで複数診断を統合分析した「自分の総合レポート」を生成
- 就活・転職の自己PR資料や、チームメンバーの相互理解ツールとして活用できる

### プラットフォーム機能

- ユーザーアカウント：診断履歴の保存・過去結果の参照
- タイプ別コミュニティ：同じタイプのユーザーが集まる場
- BtoB：チーム全員の診断結果を組織として可視化するダッシュボード

### AI活用の深化（有料機能）

- 有料 AI レポート：複数診断の統合分析レポート生成
- 診断設計支援：新しい診断の質問・タイプ設計を AI でアシスト（開発者向け）
- パーソナライズコメント：有料版のみ AI による個別フィードバック
