# MONETIZATION.md — 収益化設計

## 収益化の基本思想

このプラットフォームの収益化は「無料診断の体験を損なわずに、自然な導線で広告・アフィリエイト・有料レポート・BtoB へ広げる」が原則です。

- **無料診断は完全無料・広告は最小限**：まず診断を楽しんでもらい、信頼を築く
- **有料機能は「もっと深く知りたい」欲求に応える**：強制しない
- **アフィリエイトは診断結果に自然に紐づける**：押し付けでなく、必然として見せる
- **BtoBは将来の収益柱**：個人向けで実績を作ってから展開する。安売りしない

### 収益化の優先順序

```
Phase 1〜2：無料診断で SNS 拡散・SEO 流入を獲得（収益より認知優先）
Phase 2〜3：AdSense・アフィリエイトで収益化を開始
Phase 4  ：有料AIレポートを追加（Human Profile と連動）
Phase 5  ：PDFレポート・BtoB を本格展開
```

有料AIレポートを初期から強く押し出さない。無料診断で信頼を積み上げてから有料化する。

## 1. Google AdSense

### 概要

診断結果ページ・診断一覧ページに広告を設置する最もシンプルな収益化。

### 設置方針

| 設置箇所 | 広告タイプ | 優先度 |
|---|---|---|
| タイプ別固定ページ下部 | ディスプレイ広告（レスポンシブ） | 高 |
| 診断一覧ページ | ディスプレイ広告 | 中 |
| 診断説明ページ | ディスプレイ広告 | 中 |
| 質問ページ | 設置しない（離脱防止） | なし |
| 個人結果画面 | 設置しない（体験優先） | なし |

### 導入タイミング

Phase 1 公開後からすぐに申請準備を始め、**Phase 2 前後での承認取得**を目標にする。

AdSense の審査は PV 数だけでなく、サイトのコンテンツ量・信頼性・法的ページの整備を重視する。以下をすべて揃えてから申請する。

**申請前に必要なページ一覧：**
- [ ] プライバシーポリシー
- [ ] お問い合わせ
- [ ] 免責事項
- [ ] 運営者情報
- [ ] 各診断の説明ページ（少なくとも1〜2本）
- [ ] 独自コンテンツ記事（タイプ解説・診断活用記事 数本）

### 収益見込み

| 月間PV | 想定RPM | 月間収益目安 |
|---|---|---|
| 10,000 | ¥300 | ¥3,000 |
| 50,000 | ¥350 | ¥17,500 |
| 200,000 | ¥400 | ¥80,000 |

RPM（Revenue Per Mille）：1,000 PV あたりの収益。AdSense 管理画面で確認できる実績ベースの指標。

## 2. アフィリエイト

### 概要

診断結果に関連するサービス・書籍・商品へのリンクを設置する。広告よりも診断との親和性が高く、クリック単価も高い。

### 広告・アフィリエイト表記の義務

アフィリエイトリンクを設置するページには、必ず以下の表記を行う。

```
このページには広告・アフィリエイトリンクが含まれます。
```

- タイプ別固定ページのリンク近傍に表記
- 結果ページに記事コンテンツを追加する場合も同様
- ステルスマーケティング規制（景表法）への対応として必須

### 連携先（カテゴリ別）

| 診断カテゴリ | アフィリエイト先 | プログラム | 優先度 |
|---|---|---|---|
| キャリア・社会人能力 | 転職サービス（リクルート・マイナビ等） | 各社ASP | 高 |
| 住宅・ライフプラン | 住宅ローン比較・不動産一括査定 | 各社ASP | 高 |
| マネー・投資 | 証券口座開設・FP無料相談 | 各社ASP | 高 |
| 学習・スキルアップ | オンライン学習（Udemy等） | 各社ASP | 中 |
| 書籍 | Amazon アソシエイト | Amazon | 中 |
| AI・ツール | AIツール・タスク管理ツール | 各社ASP | 中 |
| 人間関係・恋愛 | マッチングアプリ | 各社ASP | 中 |
| メンタル・健康 | カウンセリングサービス | 各社ASP | **低（後述）** |

### メンタル・健康系カテゴリの取り扱い

ストレス耐性・燃え尽き度・メンタルヘルス・カウンセリング誘導などのカテゴリは、収益性はあるが**表現リスクが高い**。

- 診断結果の表現が医療的助言と受け取られるリスクがある
- カウンセリングへの不適切な誘導として問題になる可能性がある
- **MVP〜初期フェーズでは優先度を下げる**
- 法務確認・表現チェックを行った上で展開する（Phase 3 以降に慎重に検討）

### 設置方針

- タイプ別に「このタイプにおすすめのリソース」として自然に表示
- `types.json` 内の `affiliateLinks` フィールドにタイプごとのリンクを定義
- 過度なリンク設置は避ける（1結果ページあたり2〜3本まで）

### 導入タイミング

- Phase 1 から書籍アフィリエイトを設置（JSON で定義するだけ）
- Phase 2（住宅チェッカー）から高単価の住宅・転職アフィリを本格設置
- Phase 3 以降、診断カテゴリ拡張に合わせて連携先を追加

## 3. 有料詳細診断（AIレポート）

### 概要

無料診断の固定タイプ結果に加え、AI が個別に分析した詳細レポートを有料で提供する。Phase 4 以降に導入。Phase 1〜3 は無料体験の品質向上を優先する。

### 無料 vs 有料の差分

| 項目 | 無料 | 有料（AIレポート） |
|---|---|---|
| タイプ判定 | ✓ | ✓ |
| 5軸レーダーチャート | ✓ | ✓ |
| タイプ説明（固定） | ✓ | ✓ |
| 辛辣コメント | ✓ | ✓ |
| 個別コメント | ✗ | ✓（AI生成） |
| 詳細な強み・弱み分析 | ✗ | ✓（AI生成） |
| 改善アドバイス | ✗ | ✓（AI生成） |
| PDF ダウンロード | ✗ | ✓ |
| 複数診断の統合分析 | ✗ | ✓（Human Profile） |

### 価格設計

| プラン | 価格 | 内容 |
|---|---|---|
| 単品AIレポート | ¥500〜¥800 | 1診断のAI詳細分析 |
| Human Profile AIレポート | ¥1,500〜¥2,000 | 複数診断の統合分析 |
| BtoBチームレポート | 要問い合わせ | チーム全員の統合分析 |

### 技術実装（Phase 4以降）

1. ユーザーが「詳細レポートを見る」ボタンをタップ
2. Stripe で決済
3. 決済完了後、ユーザーの回答データを LLM API に送信
4. AI が個別分析テキストを生成
5. PDF に整形してメール送付 or ページ表示

LLM API は特定のサービスに固定しない。OpenAI / Claude / Gemini など複数のモデルを比較・差し替えできる設計にする。環境変数でモデルを切り替えられるよう実装する。

### 導入タイミング

- **Phase 4**（Human Profile 導入後）から提供開始
- 決済は Stripe を使用
- AI 生成コストは使用する LLM API の従量課金

## 4. PDFレポート

### 概要

AI生成テキスト + デザインテンプレートを組み合わせた PDF レポートを自動生成・販売する。

### 価値提案

- 印刷・保存できる「自分の取扱説明書」
- 就活・転職の自己 PR 資料として活用できる
- プレゼントとして「友人の診断PDFを買ってあげる」用途も想定

### 技術実装

- PDF 生成：`@react-pdf/renderer` or Puppeteer によるヘッドレスレンダリング
- テンプレートは診断カテゴリごとに設計
- Vercel の Serverless Function で生成・Supabase Storage に保存

### 導入タイミング

- **Phase 5** から本格展開
- Phase 4 で有料AIレポートのニーズを確認してから実装

## 5. BtoB展開

### 概要

チームや組織単位で診断を活用したい企業・人事向けのサービス。

### 想定ユースケース

- **採用・面接前の候補者特性把握**：候補者に診断を受けてもらい、面接の参考にする
- **チームビルディング**：チーム全員の診断結果を可視化し、役割分担を最適化する
- **研修・1on1の補助資料**：マネージャーが部下の特性を理解するための入口として使う
- **エンゲージメントサーベイの代替**：定期的に診断を受けさせ、変化を追跡する

### 収益モデル

BtoB はサポート・カスタマイズ工数が発生する。個人向け価格の感覚で安売りしない。

| プラン | 価格 | 内容 |
|---|---|---|
| 小規模チームプラン | ¥15,000〜¥30,000/月 | 最大20名、チームダッシュボード、メールサポート |
| 企業プラン | ¥50,000/月〜 | 人数無制限、統合分析、CSV エクスポート、優先サポート |
| 導入支援 | ¥100,000〜¥300,000 | 診断設計・研修コンテンツ組み込み・社内展開支援 |

### 導入タイミング

- **Phase 5 以降**、個人向けで一定のブランド認知ができてから展開
- まずは小規模チームへの限定トライアルから始める
- 法人営業・導入支援は Phase 5 後半から本格化

| フェーズ | 主な取り組み | 主な収益源 | 月間収益目安 |
|---|---|---|---|
