## 5. 5能力の定義

| キー | 表示名 | 定義 |
|---|---|---|
| `logic` | 論理力 | 目的、前提、事実、因果、判断基準を分け、根拠のつながった判断を作り、情報に応じて更新する傾向。 |

## 7. 内部スコアと画面表示スコア

### U値（生スコア）

寄与側の強い回答=2、やや回答=1、反対側=0として合計する。範囲：`[0, 2 × n_k]`。

### 内部正規化値 V（0〜100）

```
V_k = Math.round(50 × U_k / n_k)
```

実装：`ability-scorer.ts` の `uToV(u, n)`

既存の計算・simulation・特化個体の説明に使用する内部基準。画面に直接表示しない。

### 画面表示値 D（50〜100）

```
D_k = 50 + Math.round(V_k × 0.5)
```

実装：`ability-scorer.ts` の `vToDisplayScore(v)`

| 内部 V | 画面 D |
|---:|---:|
| 0 | 50 |
| 20 | 60 |
| 50 | 75 |
| 70 | 85 |
| 100 | 100 |

- レーダーと表示数値は D を使用する
- 単調変換のため順位逆転なし
- 50 は平均・合格点・最低能力を意味しない

## 8. `av`パラメータ

```
av=1.{logicU}.{executionU}.{salesU}.{creativityU}.{managementU}
```

`av` には U 値を保存する。形式・範囲・バージョンは変更しない。
不正時はスキルバランスと特化個体を表示しない。

実装：`ability-scorer.ts` の `parseAvParam` / `buildAvParam`

---

## 9. 特化個体

### 判定条件

1. U 値を能力別観測数で正規化した比率が単独1位
2. 能力別の内部基準 `minV` 以上
3. 1位と2位の内部差が `minGap=10` 以上
4. 最大1個

| 能力 | minV | 実効 U 下限 |
|---|---:|---:|
| 論理力 | 70 | 17/24 |
| 実行力 | 68 | 11/16 |
| 営業力 | 76 | 7/8 |
| 創造力 | 71 | 10/14 |
| 管理力 | 71 | 8/10 |

判定は表示 D ではなく生の U 値を整数クロス積で比較する。
画面表示を 50〜100 へ変換しても特化個体の有無・種類・出現率は変えない。

```
50 × U_top >= minV_top × n_top

50 × (U_top × n_second - U_second × n_top)
>= 10 × n_top × n_second
```

実装：`src/engine/specialist-resolver.ts`（変更禁止）
