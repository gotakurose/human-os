## 作業開始時の注意

- **対象診断を最初に特定する。** 対象外の診断固有仕様を混ぜない。
- 共通仕様に診断固有の詳細（質問文、タイプ名、採点）を記載しない。
- 実装 JSON（`data/`配下）は実行用データであり、正本仕様書とは役割が異なる。
- 正本と実装が不一致の場合はコードを自動的に正とせず、差分を報告すること。
- `docs/` 内の旧フォルダ（`human-os/`、`v1-fix-draft/` 等）は参照しない。
