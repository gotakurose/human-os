## 1. Human OS のブランドとプラットフォーム構造

Human OS は複数の診断を提供するプラットフォームである。個別の診断コンテンツはその下位に位置する。

| 項目 | 値 |
|---|---|
| ブランド名 | Human OS |
| 位置づけ | 診断プラットフォーム（上位） |
| V1 公開診断 | ビジマル診断のみ（詳細は診断一覧マスター参照） |
| 将来構想 | 複数診断の統合・追加。V1 では未実装 |
| 本番ドメイン | `https://human-os.site` |
| 公開日基準 | 2026年7月8日 |

Human OS とビジマル診断を同一名称として扱わない。

## 2. Human OS トップページ `/`

### 役割

- Human OS が上位プラットフォームであることを示す
- 現在利用可能な診断へ誘導する
- 将来の複数診断追加構想を、現在利用可能な機能と誤認させない形で説明する

### V1 の主要表示

- `Human-OS`
- 「人間の全てを可視化する診断プラットフォーム」

### 診断カードの構成方針

- 新診断を追加する場合は診断一覧マスターに登録後、カードを追加する

## 9. 外部送信・広告・アクセス解析方針

### V1 で使用しない

- Google Analytics 4
- Vercel Analytics / Speed Insights
- 広告配信タグ
- アフィリエイト計測タグ
- 外部問い合わせフォーム
- Cookie による診断履歴
- localStorage / sessionStorage による診断履歴
- AI API
- Stripe

### 使用する（V1）

- Vercel 等の配信基盤でアクセスログが記録される可能性
- X・LINE 共有 URL をユーザー操作時のみ開く

### Google AdSense について

V1 リリース後に AdSense スクリプトを layout.tsx へ追加していたが、無効な DOM 位置（`</body>` 後・`</html>` 内）への配置が React hydration エラーを引き起こした。このため AdSense スクリプトは root layout から削除済み。

AdSense を再導入する場合は以下をすべて同時に実施する：

- AdSense スクリプトを正しい位置（`<head>` 相当）へ配置
- `public/ads.txt` の確認
- プライバシーポリシーの広告・Cookie 項目を更新
- 外部送信説明を実態に合わせて更新

現時点では AdSense は公開対象外。

## 11. プライバシーポリシー

正式 URL：`/privacy`
施行日：2026年7月8日
実装ファイル：`src/app/privacy/page.tsx`

### 基本方針

Human-OS およびビジマル診断（以下「本サイト」といいます。）は、本サイトの提供と安全な運営に必要な範囲で、利用者に関する情報を取り扱います。

本サイトは、診断回答や診断結果を利用者ごとの診断履歴として保存せず、V1 ではアクセス解析、広告配信、アフィリエイト計測、問い合わせフォームを使用しません。

### 診断回答と診断結果

40問への個別回答は、診断中のブラウザ画面内で処理されます。本サイトは、個々の回答内容を診断履歴としてサーバーまたはデータベースへ保存しません。

診断結果も、利用者ごとの履歴としてサーバーまたはデータベースへ保存しません。localStorage および sessionStorage も使用しません。

診断完了後は、結果の再表示に必要な情報を結果ページの URL へ含めます。結果 URL には、診断タイプ、4 軸スコア、5 能力値の算出に用いる内部スコアが含まれます。

結果 URL を保存すれば、ブラウザを閉じた後でも同じ結果を再表示できます。結果 URL を第三者へ送信または公開した場合、その URL を知る第三者も結果を閲覧できます。公開を望まない場合は、結果 URL を共有しないでください。

結果ページには検索エンジンへの登録を抑制する設定を行いますが、この設定は閲覧制限や秘密保持を保証するものではありません。

### アクセス時に記録される可能性がある情報

本サイトの配信、安全管理、障害対応に伴い、ホスティング事業者のサーバーまたはログへ、IPアドレス、ブラウザや端末に関する情報、アクセス日時、アクセス先 URL、クエリ文字列、HTTP ステータス、User-Agent 等が記録される場合があります。

結果ページへアクセスした場合、アクセス先 URL やクエリ文字列の一部として、結果の再表示に必要な情報がログへ含まれる場合があります。

これらの情報は、サイト配信、セキュリティ確保、障害調査、不正利用防止のために取り扱い、診断結果の個人別プロフィール作成、広告配信、営業活動には使用しません。

### Cookie・アクセス解析・広告

V1 の本サイトは、独自の Cookie を利用したログイン、診断履歴保存、アクセス解析、広告配信、アフィリエイト計測を行いません。

Google Analytics 4、Vercel Analytics、Vercel Speed Insights、広告配信タグ、アフィリエイト計測タグは使用しません。

将来これらの機能を追加する場合は、公開前に本ポリシーを改定し、必要に応じて利用者への告知または同意取得を行います。

### 外部サービスへの共有

結果ページには、X および LINE への共有ボタンを設置します。

本サイトは、これらのサービスの埋め込み SDK や常駐スクリプトを読み込みません。利用者が共有ボタンを押した場合に限り、共有先サービスのページを開きます。

共有ボタンを押した後に共有先サービスが取得する情報は、各サービスの利用規約およびプライバシーポリシーに従って取り扱われます。

### 第三者提供

本サイトは、法令に基づく場合を除き、本サイトが保有する個人情報を本人の同意なく第三者へ提供しません。

V1 では、診断回答と診断結果を個人別の診断履歴として保有しません。

### 安全管理

本サイトは、通信の暗号化、不要な外部送信の抑制、診断データの非保存、アクセス権限の管理等、取り扱う情報の内容に応じた安全管理に努めます。

結果 URL には診断情報が含まれるため、利用者自身も、公開範囲を確認したうえで共有してください。

### ポリシーの変更

本サイトの機能、利用する外部サービス、法令その他の事情が変わった場合、本ポリシーを変更することがあります。

重要な変更がある場合は、本サイト上で分かりやすく告知します。

### 運営表示

本サイトの運営表示名は「Human-OS」です。
