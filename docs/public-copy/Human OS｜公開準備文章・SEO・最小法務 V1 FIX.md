6. 診断について
ページ名：診断について
推奨URL：`/about-diagnosis`
ページタイトル：診断について｜Human OS
掲載本文
ビジマル診断は、40問への回答から、仕事における思考・行動・判断・役割の傾向を整理するビジネスアニマル診断です。
診断結果には、16タイプ、4軸、5能力値、族バッジ、ならびに条件に該当した場合の特化個体バッジが表示されます。
この診断が示すもの
本診断は、回答時点で利用者が選んだ「仕事上の場面で取りやすい行動」を一定のルールで整理し、傾向として表示します。
結果は、自分がどのように考え、動き、他者と役割を分け、選択肢を広げたり絞ったりしやすいかを見直すための参考情報です。強みだけでなく、本人には合理的に見えている癖、周囲との認識差、行き過ぎた時の弱点も含めて表示します。
この診断が示さないもの
本診断は、実技能試験、IQ検査、学力検査、採用適性検査、人事評価、医療・心理診断、疾患や障害の診断、人格の優劣判定、職業適性や将来の成果の断定を目的とするものではありません。
診断結果だけを根拠として、採用、不採用、配置、昇進、契約、治療、退職、転職その他の重要な判断を行わないでください。
16タイプと4軸について
16タイプは、4つの軸の組み合わせから、仕事上の傾向を理解しやすい形へまとめたものです。同じタイプであっても、各軸の強さや5能力値の出方により、実際の行動は異なります。
タイプ名や動物キャラクターは、結果を記憶しやすくするための表現です。利用者の人格全体を動物や役割へ固定するものではありません。
5能力値について
5能力値は、論理力、実行力、営業力、創造力、管理力について、40問への回答の中で、それぞれに関わる仕事上の行動傾向がどの程度観測されたかを0〜100で示すものです。
この数値は、実技能の達成率、正答率、偏差値、母集団内順位、他者との優劣または仕事能力の絶対評価ではありません。50を平均値と解釈することもできません。
能力ごとに観測へ用いる回答数や観測する行動の範囲が異なるため、数値を単純なランキングとして扱わないでください。低い数値は、無能、不得意または能力不足を意味しません。その能力に関わる行動が、今回の質問と回答の中で強く観測されなかったことを示します。
結果が変わる場合
回答時の役割、経験、職場環境、直近の業務、心身の状態、質問の解釈等により、結果が変わる場合があります。
再診断によって結果が変わった場合も、どちらかが誤りとは限りません。異なる状況で、異なる行動を選びやすいことが反映されている可能性があります。
結果の使い方
診断結果は、自分の判断や行動の癖を言語化すること、強みが裏返った時の弱点を確認すること、上司・同僚・部下・共同経営者等との役割分担を話し合うこと、自分に合う仕事環境や裁量の条件を考えることを想定しています。
診断結果に違和感がある場合は、無理に受け入れる必要はありません。どの質問への回答が自分の実態とずれていたか、場面によって行動が変わるのかを見直す材料として利用してください。
免責
診断結果の完全性、正確性、特定目的への適合性、利用者の将来の成果または第三者からの評価を保証するものではありません。
利用者が本診断または診断結果を参考に行った判断や行動について、Human OSは責任を負いません。ただし、法令により責任を免除できない場合を除きます。

取得する情報
本サイトでは、次の情報を取得する場合があります。
·  診断の回答および診断結果の表示に必要な情報
·  IPアドレス、ブラウザ、端末、アクセス日時、閲覧ページ等、サーバー等により自動的に記録される情報
·  お問い合わせ導線を設けた場合に、利用者が自ら送信した情報
利用目的
取得した情報は、次の目的で利用します。
·  診断機能と診断結果を提供するため
·  サイトの表示、動作、利用状況を確認し、改善するため
·  不正利用の防止、セキュリティ確保、障害対応のため
·  お問い合わせへ対応するため
診断回答・診断結果の取扱い
公開時に、実際の仕様と一致する次のどちらか一方だけを掲載する。
A｜回答・結果を診断履歴として保存しない場合
診断回答は原則として利用者の端末上で処理され、個々の回答内容や診断結果を診断履歴として保存しません。ただし、サイトの配信や安全な運営に必要なアクセスログ、エラーログ等が記録される場合があります。
共有URLを発行する場合、URLに診断結果の表示に必要な情報が含まれることがあります。公開を望まない場合は、共有URLを第三者へ送信または公開しないでください。
B｜回答または結果を保存する場合
診断機能の提供、障害対応およびサイト改善のため、診断回答または診断結果を保存する場合があります。保存した情報は、利用目的に必要な範囲で取り扱い、不要になった情報は削除します。
共有URLを発行する場合、URLに診断結果の表示に必要な情報が含まれることがあります。公開を望まない場合は、共有URLを第三者へ送信または公開しないでください。
Cookie・アクセス解析等
公開時に、実際の仕様と一致する次のどちらか一方だけを掲載する。
A｜アクセス解析・広告配信を行わない場合
現在、広告配信や行動追跡を目的としたCookieは使用していません。サイトの基本機能や安全な提供に必要な保存技術を使用する場合があります。
B｜アクセス解析を利用する場合
本サイトでは、利用状況の把握と改善のため、アクセス解析サービスを利用する場合があります。これにより、閲覧ページ、利用端末、参照元、操作状況等の情報がCookieその他の技術を通じて取得される場合があります。
広告またはアフィリエイトを導入する場合は、広告であることを分かる形で表示し、本項を実態に合わせて更新します。
第三者への提供
取得した情報は、本人の同意がある場合または法令に基づく場合を除き、第三者へ提供しません。サイトの運営に必要な範囲で外部サービスを利用する場合は、必要な情報のみを取り扱います。
情報の管理
取り扱う情報への不正アクセス、漏えい、改変等を防ぐため、サイトの規模と情報の性質に応じた管理を行います。
内容の変更
本ポリシーは、サイトの機能や利用するサービスの変更に応じて更新することがあります。
