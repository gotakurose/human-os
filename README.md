# Human OS — AI診断プラットフォーム

100種類以上の診断を提供・追加できるAI診断プラットフォームです。

## コンセプト

「自分を知る」ための診断を、AIを活用して誰でも手軽に体験・作成・拡張できるプラットフォームを目指します。性格、思考傾向、才能、ライフスタイル、キャリア適性など、あらゆる角度から自己理解を深める診断を100種類以上収録予定です。

## 特徴

- **100種類以上の診断** — 多様なジャンルの診断コンテンツを随時追加可能な拡張性の高い設計
- **AIによる分析** — 回答をもとにAIがパーソナライズされた診断結果を生成
- **診断の追加が容易** — 新しい診断をデータとして定義するだけで簡単に追加できる構造

## ディレクトリ構成

```
Human-OS/
├── docs/       # 設計ドキュメント・仕様書
├── data/       # 診断コンテンツデータ（質問・選択肢・結果定義など）
├── public/     # 静的アセット（画像・アイコンなど）
└── README.md
```

## 診断ジャンル（予定）

- 性格・気質
- 思考・認知スタイル
- 才能・強み
- キャリア・適職
- 人間関係・コミュニケーション
- ライフスタイル・価値観
- メンタル・ウェルネス
- その他（随時追加）
